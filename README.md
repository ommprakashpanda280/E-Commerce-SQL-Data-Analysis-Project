E-Commerce SQL Data Analysis Project

📌 Project Overview

This project is an E-Commerce database analysis project developed using MySQL.
The project focuses on managing customers, products, orders, order items, and payments and performing SQL-based data analysis.

🎯 Project Objective

- Manage e-commerce customer and product data
- Analyze orders and sales
- Track product quantities and categories
- Analyze payment methods and payment status
- Perform multi-table analysis using SQL JOINs
- Use subqueries and set operations for advanced analysis

🗄️ Database

Database Name: "sql_mini_project"

Tables

1. "customers" — Customer information
2. "products" — Product catalog
3. "orders" — Order information
4. "order_items" — Products included in each order
5. "payments" — Payment information
